Smart Absence

Smart Absence adalah sebuah aplikasi absensi digital yang dikembangkan untuk meningkatkan proses pencatatan kehadiran harian siswa-siswi secara real-time, akurat, dan dapat diakses dari mana saja.

Platform

Tersedia di
Android & Web

Smart Absence tersedia di dual-platform yaitu Android dan Website dan sinkron secara real-time.

Android
Absen dengan hanya cukup klik tombol dari smartphone kamu. Ringan, aman dan siap digunakan.
✓ Platform Utama Download APK
Web App
Akses dashboard, laporan, dan kelola data absensi dari browser kapan saja, tanpa perlu install.
✓ Tersedia Buka Web App

Tampilan Aplikasi

Absensi personal
